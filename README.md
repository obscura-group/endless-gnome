# endless-gnome
Endless Gnome é um jogo 2D de Plataforma e Top-Down, desenvolvido na Godot Engine, com foco em ação, aventura e exploração.  O jogo combina combate, exploração, puzzles e progressão por fases, utilizando Pixel Art 2D e uma ambientação que mistura fantasia, ficção e elementos pós apocalípticos.
